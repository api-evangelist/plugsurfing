- [Batch locations](https://developer.plugsurfing.com/reference/getLocationsBatch.md): Retrieve locations in batches. Locations are returned sorted by last_updated timestamp in ascending order. Prices are not included, to get prices for a given location, use Get location by id. Best practices
- [Get list of operators](https://developer.plugsurfing.com/reference/listOperators.md): Returns the list of Charging Point Operators (CPOs) whose chargers are available through the geosearch endpoints. Can be used to let users filter on specific operators
- [Create user](https://developer.plugsurfing.com/reference/createUser.md): Only the `id` field is required (any string is accepted) when you are the Merchant on Record. - [Read user details](https://developer.plugsurfing.com/reference/getUser.md): Getting user data based on passed userId
- [Update user details](https://developer.plugsurfing.com/reference/updateUser.md): This endpoints lets you update a given user's email, VAT number and billing address.
- [Remove user](https://developer.plugsurfing.com/reference/deleteUser.md): Disables all charging keys of the user immediately and schedules the user's deletion for 30 days later. This delay ensures that late-arriving Charging Detail Records (CDRs) can still be linked to the user. Note: If Plugsurfing handles payments, users with outstanding debt cannot be deleted.
- [Add user to user group](https://developer.plugsurfing.com/reference/createUserGroupMembership.md): Creates a membership link between the user and the specified user group.
- [Remove user from user group](https://developer.plugsurfing.com/reference/deleteUserGroupMembership.md): Deletes the membership link between the user and the specified user group.
- [Activate a charging key](https://developer.plugsurfing.com/reference/activateUserChargingKey.md): Activates a charging key for a specific user. The key must exist and be unassigned. Once activated, the key can be used to start charging sessions.

- [Get user's charging keys](https://developer.plugsurfing.com/reference/listUserChargingKeys.md): Retrieves all charging keys associated with a specific user. This includes both active and inactive keys, physical and virtual keys. The response contains detailed information about each key including its status, type, and validity period.
- [Create a charging key](https://developer.plugsurfing.com/reference/createUserChargingKey.md): Creates a new charging key for a specified user. Important notes: - The key will be created in an enabled state by default - Contract id, keyIdentifier and visualNumber must be provided.
